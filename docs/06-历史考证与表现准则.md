# 06 · 历史考证与表现准则

> 本作以真实历史事件为骨架。**史实是底线，戏剧化必须声明。**

---

## 1. 考证等级（每一关都要标注）

| 等级 | 含义 | 示例 |
|---|---|---|
| **A 可考证** | 日期、番号、地点、事件均有公开史料支持 | 1941-06-22 德军第 45 步兵师强攻布列斯特要塞 |
| **B 合理推演** | 事件真实，但玩家所在的小单位/具体交火为推演 | 玩家作为第 42 步兵师某连的一名步枪兵 |
| **C 戏剧化** | 为玩法需要而压缩、放大或合并的真实事件 | 把持续数周的围城压缩为一场 25 分钟战斗 |

**实现要求**：每关 \`historical_accuracy.verified_events\` 列 A 级事实，\`dramatized\` 列 C 级处理。二者缺一不可（数据校验器强制检查）。

## 4. 番号与术语规范

- 苏军：**方面军 → 集团军 → 军 → 师 → 团 → 营**（例：第 62 集团军第 13 近卫步兵师第 42 团）
- 德军：**集团军群 → 集团军 → 军 → 师**（例：第 6 集团军第 14 装甲军第 16 装甲师）
- 美军：**集团军群 → 集团军 → 军 → 师 → 团 → 营**（例：第 1 集团军第 1 步兵师第 16 步兵团）
- 术语使用史料原名：\`Gegenangriff\`（反冲击）、\`Volkssturm\`（国民突击队）、\`Panzerfaust\`（铁拳）、\`Katyusha\`（喀秋莎）
- 地名同时给出中文与原文（\`location_zh\` / \`location_en\`）与坐标

## 6. 表现准则（内容伦理）

1. **不美化战争**：没有"史诗胜利"式过场；胜利画面只有疲惫的士兵与废墟。
2. **不塑造超人**：玩家会饿、会渴、会怕、会跑不动；呼叫炮击可能炸死自己人。
3. **不煽动仇恨**：敌军以"士兵"而非"恶魔"呈现；战斗中的德军同样会恐惧、会撤离、会投降（规划中含"接受投降"）。
4. **尊重平民**：关卡背景中的平民不作为可击杀目标；任何对平民的伤害都会导致任务失败与文案谴责（规划中实现）。
5. **明确的内容提示**：启动时提示"本作包含战争暴力与历史政治符号的历史还原呈现"，并提供关闭政治符号的选项（合规）。
6. **不使用纳粹符号作为可收集/装饰要素**。敌方旗帜使用识别性但不做美学强调。
