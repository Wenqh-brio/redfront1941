# 03 · 战斗系统与支援火力

> 数据源：`data/weapons.json`、`data/enemies.json`、`data/support.json`；原型实现见 `prototype/js/game.js`（已通过 752 项无头断言）。

## 1. 射击模型（真实性优先，但可玩）

每发子弹是一个**有飞行时间、会被掩体拦截、按穿深判定装甲**的实体，而不是命中扫描。

```
散布角 = 基础散布(武器精度) × 移动(×1.45/冲刺×2.2) × 蹲伏(×0.68)
        × 瞄准(×0.45) × 两脚架(×0.50) × 负重档位(超载×1.5)
        × 体力(<30 时 ×1.25) × 饥渴(<25 时 ×1.3)
        × 伏特加(×1.25) × 被压制(最多 ×1.45) × 低温(×1.2)
        × 后坐累积(1 + recoil×0.08)
```

- **基础散布** `SPREAD_BASE × (1.35 − accuracy) × 3.2`（精度 0.92 的莫辛 ≈ 0.041 rad ≈ 2.4°）
- **弹速**：步枪/冲锋枪 1400 u/s，火箭 420 u/s，火焰 260 u/s；子弹在有效射程外按 `life = range/speed + 0.25` 消失
- **命中判定采用线段×圆连续碰撞**（原型已修复高速弹丸穿透问题：46 u/帧 vs 20 u 直径目标）
- **后坐**：每发增加 `damage/120`，以 3.4/s 恢复；影响后续散布

### 1.1 换弹

`reload_s` 为基准；冲锋枪专长 ×0.7，超载 ×1.25，弹药携行具 ×0.92。
备弹按**口径池**统一管理（7.62x25 的 PPSh 与 TT-33 共用）——这是真实后勤压力，也让缴获武器（9mm Kurz）难以补给。

### 1.2 掩体与视线

- `blocksSight` 的障碍（建筑、树、货车、树篱）阻断视线与子弹
- **沙袋/矮墙只挡子弹不挡视线**，提供 60% 掩蔽
- 炮火可摧毁建筑（`hp 400`），摧毁后变成瓦砾通道（掩蔽降到 20%）——**地形会被战斗改变**

## 2. 装甲与穿深

| 判定 | 规则 |
|---|---|
| 等效装甲 | 正面 = `armor_mm`；侧面 = `armor_mm × side_rear_ratio`；后方 = 侧面 × 0.7 |
| 击穿 | `pen ≥ 等效装甲` 才造成伤害；`pen > 1.4×等效` 伤害 ×1.15 |
| 跳弹 | 未击穿 → 火花特效 + 无伤害（**必须侧射虎式**） |
| 断带 | 命中且有 22% 概率使载具失去机动 6 秒（期间侧后方命中 +40%） |

真实穿深参考：PTRD-41 = 35mm、RPG-43 = 75mm、巴祖卡 = 90mm、ISU-152 = 110mm、虎式正面 = 100mm。

## 4. 支援火力系统（本作的核心差异化）

### 4.1 三重约束

1. **指挥点 CP**：起始 2，上限 10，回复 0.035/s（×难度系数）；完成目标 +2，连续击杀 +0.2，摧毁载具 +0.6
2. **通讯延迟**：从呼叫到弹着最快 12 秒（82mm），最慢 75 秒（ISU-152）——你必须提前预判，而不是按按钮
3. **观察条件**：无线电台（2.4 kg，占 1 槽）必须携带且未被摧毁；部分支援需视线/标记

**失败模式（真实且残酷）**：
- 电台被摧毁 → 60 秒内无法呼叫任何支援
- 老兵/史实难度 → 呼叫后 25% 概率遭**敌方无线电测向反炮兵**（炮弹落在你自己的位置）
- 敌方前沿观察员/班长存活 40-55 秒后会**呼叫迫击炮**打你
- 空中支援可能被 **Flak 36** 拦截（35%/门，最多两门）
- **危险距离**：炮弹会误伤友军与玩家（喀秋莎最小安全距离 150m）

## 5. 敌军 AI 与条令

### 5.1 感知模型（原型已实现）

```
发现距离 = 基础感知(awareness_m) × 地形通透度 × 玩家暴露系数，上限 = min(能见度, 900)
地形通透度：旷野 1.7 / 战壕 1.5 / 河流 1.25 / 铁路 1.1 / 村落 1.05 / 要塞 1.0 / 森林 0.95 / 工业区 0.85 / 城市 0.8
玩家暴露系数：4 秒内开过枪/爆炸 ×1.5，蹲伏 ×0.75，望远镜观察 ×1.1，风雪 ×0.9
```

### 5.2 行为状态机

`idle → advance → fire → cover → flee`

- **advance**：向"敌军掌握的方位"（每 12 秒刷新为玩家当前位置）推进；被掩体卡住时沿切线绕行（无寻路下的掩护跃进）
- **fire**：进入 `stopDist`（步兵 150 / 机枪 260 / 狙击 380）后据枪射击；反应时间 0.8-1.8 秒后开火
- **cover**：被压制 >2.5 时寻找最近掩体，转移后重新开火
- **flee**：民兵士气崩溃 35%（国民突击队）时向后逃散
- **精英**（党卫军/伞兵）抗压制 1.3-1.35，会呼叫支援

### 5.3 敌军态势（任务类型驱动）

| 任务类型 | 敌军姿态 | 行为 |
|---|---|---|
| 防守 / 迟滞 / 伏击 | **进攻方** | 从进场即向我军推进，施加持续压力 |
| 强攻 / 突破 / 巷战 / 围城 | **防御方** | 依托支撑点固守；45-90 秒后投入预备队反击（Gegenangriff） |
| 无限模式 | 进攻方 | 每波向我军阵地冲击 |

### 5.4 协同与支援

- **无线电通报**：任一敌人发现玩家 → 全线进入战斗状态并刷新方位
- **班长/观察员**（`calls_support`）存活 40-55 秒 → 呼叫敌方迫击炮（60% 概率）
- **敌方空袭**：Ju 87 / Bf 109 / Fw 190 以空中事件形式入场（不生成地面单位），18-38 秒后投弹；暴露在开阔地会被重创
- **压制机制**：玩家连续射击同一区域 2 秒使区域内敌人移速 −30%、精度 −40%；炮击与擦身子弹同样累积压制

## 6. 伤害与死亡

| 项目 | 规则 |
|---|---|
| 玩家受伤减免 | 蹲伏 12% + 胸甲 35% + 钢盔 8%，合计上限 62% |
| 流血 | 中弹 30% 概率，持续 2.0/s；绷带/急救包可止 |
| 友军误伤 | 炮击/手榴弹对友军造成 70%-90% 伤害并记录战报 |
| 阵亡 | 新兵/标准/老兵可读检查点重开；**史实档单命** |
| 战利品 | 25% 概率掉落缴获弹药或绷带 |

## 7. 平衡红线

1. 任何单一武器不能同时具备"高射速 + 高精度 + 高穿深"。缴获 StG 44 受弹药稀缺制约。
2. 支援火力必须**慢**：如果玩家能用炮击解决所有问题，战术射击就没意义了（因此最便宜的火力也要 12 秒延迟）。
3. 敌军 AI 不许"透视"：只能在感知范围内反应，且必须满足视线条件。
4. 空袭/炮击必须能伤害玩家——否则危险距离设计失效。

## 8. 验收测试（原型已实现，UE 侧需复刻）

- 靶场：开阔地 120m 命中率 >70%，500m 仍能命中，沙袋后命中 0
- 装甲：35mm 对 100mm 正面跳弹，120mm 击穿
- 支援：15 项支援全部完成"呼叫 → 延迟 → 生效 → 冷却"完整链路
- 指挥点不足 / 未携带电台 → 呼叫被拒
- 无限模式：至少推进 5 波，每波间整备 45 秒
- 20 分钟连续仿真：无异常、无实体泄漏（粒子/子弹/敌人数有上限）
