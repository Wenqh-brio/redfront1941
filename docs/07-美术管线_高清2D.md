# 07 · 美术管线：高清 2D（非像素风）

> 目标：让玩家一眼看出"2D"，但看不出"廉价"。参考方向：《合金弹头》的可读性 + 写实手绘的光影体量 + 二战装备考据。

---

## 1. 美术方向

| 维度 | 设定 |
|---|---|
| 风格 | 高清手绘写实（realistic painterly），不做像素化，不做卡通描边 |
| 视角 | 正交俯视偏侧（2.5D 感），角色 8 方向 |
| 分辨率 | 精灵长边 **2048 px**（关键角色 4096 px），场景贴图 1024-2048 px |
| 色彩 | 四部战役四套色彩脚本（见第 5 节） |
| 光照 | 2D 伪光照：法线贴图 + 纸面阴影层 + 体积光贴片 |
| 动效 | 精灵序列帧 12-16 fps（关键动作 24 fps 抽帧到 16 帧）+ 材质动画 |

**禁止**：像素风滤镜、低分辨率放大、纯扁平色块（缺少光影体量）。

## 2. 分辨率与装配规格

### 2.1 角色/步兵（8 方向 × 6 动作）

| 动作 | 帧数 | 说明 |
|---|---|---|
| 待机 | 6 | 呼吸 + 枪口微动 |
| 行走 | 8 | 含负重感（超载时使用"慢速行走"变体） |
| 奔跑/冲刺 | 8 | 轻装变体速度更快 |
| 射击 | 6 | 肩射/腰射两套 |
| 蹲伏 | 4 | 静态+射击 |
| 卧倒/起身 | 6 | 史实档专用 |
| 受伤/阵亡 | 8 | 分"重伤"与"阵亡" |
| 换弹 | 8 | 栓动/弹匣/弹鼓三种 |

单方向 8-16 帧 → 单个士兵约 **8 方向 × 平均 9 帧 = 72 张**；使用"左右镜像 + 4 方向 + 补间插值"可压缩到 **4 方向 40 帧**（推荐，成本降低 45%）。

### 2.2 装备与载具

- 载具按**部件拆分**：车体 + 炮塔 + 履带 + 舱盖 + 损伤层（着火/履带断裂/炮塔卡死），实现动画与状态复用
- 武器作为**独立图层**挂在角色骨点上（避免"人枪合一"导致无法换装）
- 场景采用**模块化拼装**：建筑（墙/门/窗/屋顶/瓦砾）、掩体（沙袋/木箱/铁丝网/反坦克拒马）、植被（树/灌木/草丛）

### 2.3 氛围层

| 层 | 内容 | 视差系数 |
|---|---|---|
| L0 远景 | 地平线、天际线剪影、烟柱 | 0.15 |
| L1 中景 | 建筑群、树线 | 0.40 |
| L2 战场层 | 玩家、敌人、掩体、可交互物 | 1.00 |
| L3 前景 | 前景草叶、瓦砾、飘落雪花 | 1.35 |

## 3. 管线流程

```
参考收集（史实照片/技术手册）
   ↓
概念设计（silhouette 优先，先黑白后上色）
   ↓
线稿 + 明暗分块（3 层灰阶）
   ↓
上色 + 材质细节（布料/皮革/金属/木料 4 套笔刷）
   ↓
损伤与污渍变体（3 级：干净 / 使用中 / 破损）
   ↓
导出 PNG（透明，sRGB）+ 法线贴图
   ↓
导入 UE → Paper2D 精灵 → Flipbook → 蓝图动画状态机
   ↓
图集打包（同一角色动作打一张 4096 图集，减少 Draw Call）
```

## 4. 命名规范

|---|---|---|
| `SPR_` | 精灵 | `SPR_SOV_Rifleman_Walk_D1_04` |
| `FLB_` | 动画序列帧 | `FLB_SOV_Rifleman_Idle` |
| `BP_` | 蓝图 | `BP_Rifleman` |
| `DT_` | 数据表 | `DT_Weapons` |
| `DA_` | 数据资产 | `DA_Class_Rifleman` |
| `LV_` | 关卡 | `LV_SOV_01_Brest_Fortress` |
| `MAT_` | 材质 | `MAT_Smoke_Volume` |
| `VFX_` | 特效 | `VFX_Muzzle_762x54R` |
| `UI_` | 界面 | `UI_Hud_SurvivalBars` |

关卡资产名由关卡 id 生成：`LV_` + 大写 id（如 `sov_01_brest_fortress` → `LV_SOV_01_Brest_Fortress`）。

| 战役 | 主色 | 辅色 | 情绪 |

| 1941 巴巴罗萨 | 干草黄 #C2A25A | 焦土褐 #6B4F33 | 盛夏的混乱、燃烧的边境 |
| 1942 斯大林格勒 | 焦黑 #3A3A38 | 砖红 #8A3B2E | 废墟、钢铁、伏尔加的冷灰蓝 |

## 6. 特效（VFX）

| 特效 | 实现 |
|---|---|
| 枪口焰 | 2D 序列帧 + 点光源闪烁 + 屏幕微震（按口径分级） |
| 弹道 | 拖尾贴片 + 命中点材质（木屑/砖粉/金属火花/人体） |
| 爆炸 | 3 层：闪光 → 火球序列帧 → 烟尘滞留（10-20 秒） |
| 烟幕 | 体积感贴片 + 遮蔽判定区域可视化（不影响渲染） |
| 火焰 | 序列帧 + 热量扭曲材质（低成本 Shader） |
| 雪/雨 | GPU 粒子 + 地面湿滑材质覆盖 |
| 血迹 | 贴花（Decal），上限 64 个，超限替换最早 |

## 7. 性能预算（1080p60 中端 GPU）

| 项目 | 预算 |
|---|---|
| Draw Call | ≤800（精灵图集必须合批） |
| 同屏精灵 | ≤300 |
| 粒子系统 | ≤40 个活跃系统 / ≤4000 粒子 |
| 贴图内存 | ≤1.5 GB（关卡常驻 ≤900 MB） |
| 光照 | 2D 伪光照，动态光源 ≤6 个 |
| 阴影 | 仅角色/载具投影（圆形模糊阴影贴片） |

## 8. 外包与协作规范

1. 每个交付包必须含：图层化 PSD（隐藏层分组：线稿/底色/明暗/细节/损伤）+ 导出 PNG + 说明文档
2. 必须提供 3 个损伤变体与 1 个夜间变体
3. 色板必须取自第 5 节的色彩脚本（提供 ASE/Swatch 文件）
4. 交付前自检：透明边缘无白边、sRGB 无色彩偏移、尺寸为 2 的幂、图集坐标表随附
