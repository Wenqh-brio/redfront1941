# 10 · 程序化材质与美术资产生成管线

> **前提：本项目不依赖任何外部提供的模型/贴图文件。** 全部材质、贴图、特效与占位精灵由
> `tools/generate_art.py` 程序化生成，再由 `Unreal/Content/Python/rf_generate_materials.py`
> 在 UE 5.8 编辑器内自动创建 Material / MaterialInstance / Paper2D 资产。
> 美术团队后续可以**逐张替换**这些贴图（文件名与清单不变），无需改动任何代码。

---

## 1. 为什么这样做

| 问题 | 本管线给出的答案 |
|---|---|
| 没有美术团队 / 外包预算 | 立刻拿到**可用的**地形 PBR、覆盖层、贴花、VFX、UI 素材 |
| 没有模型文件 | 2D 游戏不需要模型：角色/载具以精灵表达，本管线提供结构正确的占位精灵 |
| 材质手工会拖慢迭代 | 7 个 Master Material + 69 个实例自动生成，参数化（地形/天气/战损/湿润度） |
| 换风格要重做 | 全部随机性由固定种子驱动，改一个参数即可整批重生成；也可单独替换某一张 |
| 担心"占位画风"卡住进度 | 占位精灵在**朝向、帧数、动画节奏、图集布局**上按最终规格制作，替换即生效 |

## 2. 产物总览（当前生成结果）

```
Unreal/Content/RedFront/Art2D/
├─ art-manifest.json          102 张贴图 + 7 Master Material + 69 实例 + 25 精灵表 + 15 组 VFX
├─ Environment/   9 地形 × (BaseColor 2048² + Normal 1024² + Roughness 1024²) + 3 张叠加（裂缝/烟熏/苔藓）
├─ Overlays/      8 张天气覆盖（新雪/踩踏雪/湿泥/水膜/干尘/焦土/霜冻/雨幕）+ 3 张通用叠加
├─ Decals/        12 张贴花（弹坑 3 级/废墟/血迹 3 种/履带 2 种/燃烧/脚印/水洼）
├─ VFX/           15 组序列帧（枪口焰 ×5 口径、爆炸 8 帧、烟幕 12 帧、火焰 8 帧、命中材质 ×6、弹道拖尾）
├─ Characters/    5 种苏/美/德单位 × 5 动画 × 4 方向的精灵表（560 帧）+ 单位阴影
├─ Parallax/      5 张视差背景（城市废墟/树线/工厂/雪原/旷野）
└─ UI/            9 宫格面板、暗角、颗粒、准星 3 态
```

合计约 **19 MB**，生成耗时 **~53 秒**（快速模式 `--quick` 约 17 秒 / 7.6 MB）。
UE 导入后生成 560 个方向帧 Sprite、100 个按方向分开的 Flipbook，以及苏军/美军玩家角色 Blueprint。
这些都是结构正确的占位素材，并不等于最终手绘美术。

## 3. 材质如何在 UE 中落地

### 3.1 7 个 Master Material

| 材质 | 域/混合 | 关键参数 |
|---|---|---|
| `M_Terrain_2D` | Surface / Opaque | `BaseColorTex` `NormalTex` `RoughnessTex` `OverlayTex` · `OverlayAmount` `Wetness` `UVScale` `DamageBlend` `Tint` |
| `M_Sprite_Lit` | Surface / Masked | `SpriteTex` `NormalTex` · `RimPower` `DamageFlash` `SnowDust` `Phase` |
| `M_Decal_2D` | Deferred Decal / Translucent | `DecalTex` · `Opacity` `FadeRadius` `WetShine` |
| `M_VFX_Additive` | Surface / Additive / Unlit | `VFXTex` · `EmissiveBoost` `FrameIndex` `Fade` |
| `M_Smoke_Translucent` | Surface / Translucent / Unlit | `SmokeTex` · `Density`（同时驱动视觉与遮蔽） `FrameIndex` `Tint` |
| `M_Parallax_Layer` | Surface / Translucent / Unlit | `LayerTex` · `ParallaxFactor` `FogDensity` |
| `M_UI_Panel` | UI / Translucent | `PanelTex` · `Opacity` `Tint` |

### 3.2 69 个 Material Instance

- 9 个基础地形实例（`MI_Terrain_field` …）
- 9 地形 × 5 种天气 = 45 个天气实例（`MI_Terrain_trench_snow` 等）
- 8 个覆盖层实例（`MI_Overlay_snow_fresh` …）
- 11 个贴花实例（`MI_Decal_crater_medium` …）
- 5 个视差实例（`MI_BG_city_ruins` …）

**关卡只需在 Level Blueprint / World Settings 里换成对应实例**，不必手连材质节点。
数据侧的对应关系是 `data/levels/*.json` 的 `terrain` + `weather` 字段 —— 一个脚本即可批量把 56 关的地面材质实例指定好（见第 6 节）。

### 3.3 执行方式

```powershell
# 1) 生成贴图与清单（不依赖引擎）
python tools/generate_art.py                # 全量 2048 高清
python tools/generate_art.py --quick        # 半分辨率，用于快速迭代/CI
python tools/generate_art.py --only vfx,ui  # 只重生成某几类（会与已有清单合并）

# 2) 校验产物质量（尺寸/接缝/空白/alpha/法线/引用闭合）
python tools/verify_art.py

# 3) 在 UE 编辑器内创建材质与 Paper2D 资产
#    · 编辑器：Tools → Execute Python Script… 选择 Unreal/Content/Python/rf_generate_materials.py
#    · 命令行：UnrealEditor-Cmd.exe RedFront1941.uproject -run=pythonscript -script="<上述文件>"
#    · 不装引擎也能先校验清单：python rf_generate_materials.py --dry-run
```

脚本每步都有 try/except 保护并输出 `Unreal/Content/Python/rf_materials_report.txt`：
某个 API 名称在具体引擎版本上有差异时，会记录并继续，不会中断整批导入。

## 4. 诚实说明：这些素材的定位

**可以直接使用的部分**
- 9 种地形 BaseColor / Normal / Roughness：**可平铺、有细节、有 PBR 分层**，达到"可玩版本"的地面品质
- 8 种天气覆盖层、12 种贴花、15 组 VFX 序列帧、视差背景、UI 九宫格与暗角：**成品级占位**，替换时不影响逻辑
- 7 个 Master Material 与参数体系：**与最终版一致**，换贴图即可，不用重连节点

**明确是占位、需要替换的部分**
- 角色/载具精灵（`Characters/`）：程序化几何体拼出的俯视士兵，**朝向、帧数、动画节奏、图集布局正确**，但画风是"方块人"。目标是让战斗手感、命中判定、动画状态机在**真实素材到位前**就能完整调试。
- 部分地形细节仍偏"程序化"（例如要塞砖缝过于规整）。

替换方式（无需改代码）：
1. 用同名文件覆盖 `Unreal/Content/RedFront/Art2D/...`（尺寸与帧布局保持一致）
2. 重新运行 `python tools/verify_art.py` 确认规格没破
3. 若尺寸变化，改 `to_manifest` 中的分辨率与 `sprite_sheets` 的帧宽高即可

## 5. 扩展方式

| 想加什么 | 改哪里 |
|---|---|
| 新地形 | `generate_art.py` 的 `TERRAINS` 加一项（渐变/噪声参数 + 细节函数名），并在 `DETAIL_FUNCS` 增加细节函数 |
| 新兵种 | `UNITS` 加一项（制服/头盔/武器配色与长度），`ANIMS` 已覆盖 idle/walk/fire/reload/death |
| 新 VFX | 写一个 `vfx_xxx(size, rng, frames)` 返回帧列表，在 `gen_vfx()` 里注册并补 `VFX_SHEETS` 元数据 |
| 新材质 | `build_material_defs()` 的 `MATERIALS` 加 master；`UE 脚本` 的 `build_master_materials()` 加对应分支 |
| 换风格 | 调整 `TERRAINS` 的 `stops` 色阶与 `PARALLAX` 配色即可整批换色（对应 `docs/07` 的色彩脚本） |

## 6. 与 56 关数据的联动（建议下一步）

`data/levels/*.json` 每关都带 `terrain` 与 `weather`。据此可生成关卡地面材质绑定表：

```
LV_SOV_23_OboyanMinefield   terrain=trench   weather=mud     →  MI_Terrain_trench_mud
LV_US_53_HurtgenForest      terrain=forest   weather=rain    →  MI_Terrain_forest_rain
```

`art-manifest.json` 的 `materials` 中已包含全部组合实例，映射规则为
`MI_Terrain_<terrain>_<weather>`（`clear`/`fog` 用基础实例）。建议在 UE 内用一段
Editor Utility Widget 或 `-run=pythonscript` 批处理把所有 `LV_*` 关卡的地面 Actor 一次性绑定。

## 7. 性能与导入设置

| 类别 | sRGB | 压缩 | 备注 |
|---|---|---|---|
| 地形 BaseColor / 覆盖层 / 贴花 / 视差 / 精灵 | sRGB | TC_Default | 2048² 地形贴图建议开启流送 |
| 法线 | 线性 | TC_Normalmap | 用于 2D 伪光照与地形体量 |
| 粗糙度 / 阴影 | 线性 | TC_Grayscale | 单通道，省内存 |
| VFX 序列帧 | sRGB | TC_Default | `TMGS_FROM_TEXTURE_GROUP` |
| UI | sRGB | TC_EditorIcon | 关闭 Mipmap（避免缩放糊边） |

预估贴图内存：全量约 **90-120 MB**（压缩后），在 1080p60 目标的 1.5 GB 预算内。

## 8. CI 集成

```powershell
python tools/generate_art.py --quick   # 生成（快速模式，17 秒）
python tools/verify_art.py --quick     # 校验规格、接缝、空白、alpha、法线、引用闭合
python Unreal/Content/Python/rf_generate_materials.py --dry-run   # 校验清单与创建计划
```

三条命令全部返回 0，才允许提交美术相关改动。这与数据管线（`build-data` / `validate-data`）
和原型管线（`smoke-test-*`）共同构成完整回归。
