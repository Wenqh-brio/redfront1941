# 01 · 游戏设计文档（GDD）

> 《红色前线 1941 / RedFront 1941》— 二战东线题材 2D 高清真实向小队射击游戏
> 版本 1.0 · UE 5.8 · 单机为主 · 56 关 + 无限模式

---

## 1. 一句话概念

**你是红军的一名前线士兵（或美军西线的一名班组成员），从 1941 年 6 月 22 日巴巴罗萨的第一声爆炸，一路活到 1945 年 4 月 30 日的柏林国会大厦。**
枪械会卡壳、水壶会喝空、多带两罐水就跑不动、呼叫的炮击可能落在你自己头上。

## 2. 设计支柱（每一条决策都要能追溯到支柱）

| 支柱 | 含义 | 具体机制落地 |
|---|---|---|
| **P1 重量即战术** | 装备不是菜单，是物理负担 | 4 档负重（轻/标准/重/超载）实时改变移速、体力、冲刺、翻越；水喝完真的减重 |
| **P2 活着是资源问题** | 饥饿、脱水、失温与中弹同样致命 | 饱食/饮水/体温/体力/流血 5 条生存轴，归零不是秒死，而是"能力退化 → 掉血" |
| **P3 火力来自指挥链** | 你不是超级士兵，你是一个能呼叫营连火力的人 | 指挥点 + 通讯延迟 + 观察视线 + 电台存活，四重约束；炮弹会误伤 |
| **P4 史实优先** | 装备、番号、战术、日期可考 | 1941 年不会出现豹式；每关历史注记必须含真实番号与地点 |
| **P5 2D 但不廉价** | 手绘高清 2D，不是像素风 | 2048px 长边精灵、正交相机、4 层视差、纸面光照与体积感粒子 |

## 3. 玩家体验曲线

```
紧张度
  ▲
  │                                          柏林巷战 ●
  │                         库尔斯克 ●       ╱
  │           斯大林格勒 ●  ╱        ╲      ╱
  │   布列斯特 ●───────────────●        ●  易北河会师（情感高点）
  │  ╱ 溃退期（弱火力/低支援）    ╲    ╱
  │ ● 莫斯科反攻（第一次胜利）     ╲ ╱
  └──────────────────────────────────────────────▶ 时间
   1941        1942        1943       1944      1945
```

- **第 1-12 关（溃退）**：弹药稀缺、支援申请经常失败、装备落后。教玩家"打不过就撤、能撤就拖"。
- **第 13-22 关（废墟）**：距离拉到 10-40m，冲锋枪与手榴弹主导，补给要冒险渡河。
- **第 23-32 关（钢铁）**：反坦克支撑点、雷区、观察员校射。玩家从"士兵"变成"火力指挥官"。
- **第 33-44 关（进军）**：全部支援解锁，节奏最快，代价最高（虎王、铁拳、逐楼清剿）。
- **第 45-56 关（美军西线）**：物资充沛但战术要求更高（灌木篱墙、森林、冬季防御）。

## 4. 核心循环

```
简报 → 装备与负重（唯一准备阶段）
      ↓
  部署 → 侦察/压制/机动 → 击杀或达成目标
      ↓        ↑                        ↘
  战场拾取补给 ─┘                   呼叫火力（炮击/坦克/空中）
      ↓
  目标达成 → 结算（史实注记 + 数据） → 解锁装备/专长 → 下一关
```

**每关 15-35 分钟**，par_time_s 600-2400 秒；难度 1-10 由数据表驱动。

## 5. 玩法模式

| 模式 | 状态 | 说明 |
|---|---|---|
| 战役（56 关） | 核心 | 五个战役，线性解锁，可重复挑战刷评价 |
| 无限模式 | 核心 | 随机战区 + 无穷波次；每 5 波精英波；波间 45 秒整备 |
| 挑战任务（规划） | 后续 | 单关变体：限定负重 / 单命 / 无支援 / 限时 |
| 合作（规划） | 后续 | 2-4 人联机（同一关卡，独立负重与生存） |

## 6. 关卡结构（单关）

- **主目标 1-2 条 + 次要目标 1-3 条**（数据里 `objectives[]`，含可选 `time_limit_s`）
- **敌军构成**来自 `enemy_composition`，按 3 波投放
- **敌军态势**由任务类型决定：防守/迟滞/伏击 → 敌军是进攻方；强攻/突破/巷战 → 敌军依托阵地固守，超时投入反击（Gegenangriff）
- **补给点** 0-4 处（水/食物/弹药/医疗），部分关卡为 0（许特根、巴斯托涅）
- **失败条件**：玩家阵亡（史实档单命）；或主目标超时
- **评分维度**：完成度、用时、命中率、承受伤害、负重档位、支援消耗

## 7. 进程与解锁

- 沿 56 关推进解锁：武器（30 件）、专长（9 个，其中机枪手/狙击手/反坦克/工兵/医护/迫击炮手在 1942-1943 解锁）
- 装备受**年份**约束：`captured_stg44`（1944+）、`pzkpfw_v_panther`（1943-07+）等
- 无限模式与战役共用同一套解锁池

## 8. 界面与交互

| 界面 | 关键信息 |
|---|---|
| 战役/关卡选择 | 日期、地点、任务类型、天气、难度、历史背景 |
| 作战简报 | 目标、敌军、友军、支援可用性、史实/戏剧化声明 |
| 装备与负重 | 实时总重、档位、移速/体力影响、槽位校验、推荐配置 |
| HUD | 5 条生存轴、负重档位、弹药/弹匣可视、指挥点、支援冷却、目标进度、小地图 |
| 结算 | 击杀/命中率/承受伤害/时间 + 史实注记 |

**无障碍**：色盲友好的档位配色 + 文字标签；可调字体缩放；HUD 可关闭（史实档默认精简）；按键全部可重映射；无快速反应事件（QTE）。

## 9. 音频方向（简）

- 枪声按口径区分（7.62x54R / 7.62x25 / 9mm / .30-06）；室内混响（斯大林格勒、柏林地道）
- 环境：伏尔加河渡船、MG42 的撕布声、斯图卡尖啸（触发士气减益）、雪原的风
- 音乐：低音弦乐 + 男声合唱，四部战役四种主题调性

## 10. 技术约束

- UE **5.8**，Paper2D/PaperZD，正交相机，DX12，Windows
- 目标：1080p60（中端 GPU），1440p60（高端），加载 <8s（SSD）
- 单关内存预算：贴图 ≤1.5GB、实体 ≤400、粒子 ≤4000（原型已验证）

## 11. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 负重/生存被玩家视为"麻烦" | 流失 | 轻装档位有速度奖励；所有惩罚都有 UI 因果提示；新兵档位惩罚减半 |
| 补给线断档导致关卡无法完成 | 卡关 | 每关至少 1 处补给点（除刻意设计的 2 关），且击杀敌兵有概率掉落 |
| 炮击误伤挫败感 | 差评 | 呼叫前显示危险半径与安全距离警告（原型已实现） |
| 史实争议 | 舆论 | 每关显式声明考证与戏剧化；采用克制表述；提供历史资料来源 |
| 2D 高清美术成本 | 超支 | 精灵复用 + 模块化拼装 + 后期着色；先做 8 个核心单位的完整管线 |

## 12. 成功指标（内部验收）

- 新玩家 3 关内理解"负重—生存—支援"三系统（可测：第 3 关结束问卷）
- 单关平均重复挑战 ≥2 次（说明难度有再挑战价值而非劝退）
- 史实档单命通关率 5%-15%（有挑战但不劝退）
- 关卡加载与帧率达标（见第 10 节）
