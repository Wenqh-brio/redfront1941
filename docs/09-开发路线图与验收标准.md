## 5. 验收标准

### 5.1 系统级 DoD（每个系统完成时必须满足）

1. **功能**：与本文档第 2 节的数值一致（原型为基准实现）
2. **数据驱动**：所有数值来自 `data/*.json`，代码内无硬编码魔法数
3. **可测**：至少 3 条自动化断言覆盖关键路径
4. **可观测**：关键状态在 HUD 或调试面板可见（负重档位、CP、冷却、AI 状态）
5. **无回归**：`build-data → validate-data → build-docs → check-unreal → smoke-test` 全绿
6. **文档同步**：改动同步到对应 `docs/*.md`

### 5.2 关卡级 DoD

- [ ] 通过第 05 篇第 7 节的 9 项检查单
- [ ] 3 条黄金路径（速通 / 稳健 / 火力压制）均可通关
- [ ] 四难度均可通（史实档允许 5%-15% 通关率）
- [ ] 无"开门杀"、无落地即死、无卡死点
- [ ] 历史注记与戏剧化声明齐备

### 5.3 发布级 DoD

- [ ] 1080p60 中端 GPU 稳定（1% low ≥50 fps）
- [ ] 56 关 + 无限模式全通无阻断
- [ ] 存档兼容性（跨版本迁移）
- [ ] 无障碍：全键可重映射、字体缩放、色盲标签、HUD 可精简
- [ ] 合规：内容分级自声明、符号选项、隐私（无强制联网）
- [ ] 本地化：简中/英/德/俄 四语言检查通过
